### How it is made

Katana is written almost entirely by AI agents working under a written contract (`CLAUDE.md`): every feature has to exist in the window, on the command line and in the MCP server; tests, not opinions, decide whether something works; and changes are reviewed by an independent agent before they are merged. I set the direction, make the decisions and own the result. The repository records the work: thousands of automated tests, and a commit history that shows which changes were made with an agent.

It is early software, and the README in the repository says plainly what is not done yet.

**Take a look, build it, or contribute: [github.com/kjarada/Katana](https://github.com/kjarada/Katana)**
